# backend

HTTP API, импорт, SQLite, jobs, версии чек-листов, апелляции и экспорт. Контракт в [CONTRACTS.md](../CONTRACTS.md).

## Запуск

```bash
cd backend
uv sync
uv run pytest
uv run uvicorn cqa_backend.main:app --port 8000
```

Настройки читаются из `.env` в корне репозитория, переменные окружения важнее файла. Запускайте один процесс: очередь оценок живёт внутри него.

Проверка на заглушке:

```bash
CQA_ALLOW_MOCK=1 uv run uvicorn cqa_backend.main:app --port 8000
curl -X POST localhost:8000/imports -H 'content-type: application/json' -d '{"group_id":"DEV"}'
```

Документация маршрутов: `http://localhost:8000/docs`.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `CQA_API_URL` | нет | URL API организаторов без `group_id`, в одинарных кавычках. Содержит подпись |
| `CQA_GROUP_ID` | нет | Группа, если в `POST /imports` она не передана |
| `CQA_DB_PATH` | `backend/cqa.sqlite` | Путь к базе |
| `CQA_CORS_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173` | Разрешённые источники через запятую |
| `CQA_HTTP_TIMEOUT_S` | `30` | Таймаут запроса к API организаторов |
| `CQA_EVAL_CONCURRENCY` | `4` | Сколько диалогов оценивается одновременно |
| `CQA_EVAL_TIMEOUT_S` | `300` | Предел на оценку одного диалога |
| `CQA_ALLOW_MOCK` | выключено | `1` разрешает заглушку `mock` |
| `LLM_PROVIDER`, `LLM_MODEL` | нет | Провайдер и модель оценщика |
| `LLM_PIPELINE` | `single` | Схема оценки, входит в ключ кэша |
| `OPENAI_API_KEY`, `ANTHROPIC_API_KEY` | нет | Ключи провайдеров, их читает `cqa_ai` |

Заглушка работает только при `CQA_ALLOW_MOCK=1`, даже если указано `LLM_PROVIDER=mock`. Если провайдер задан, заглушка не подставляется: при сбое диалог получает статус `failed`.

## Поведение, которое контракт не уточняет

- `Job.done` считает успешные диалоги, `Job.failed` сбойные. Задача завершена со статусом `failed`, только если не удался ни один диалог.
- Сбойный диалог остаётся запуском со статусом `failed`, пустыми `results` и итогом `null`. Текст ошибки лежит в поле `error`.
- После рестарта незавершённые задачи продолжаются с необработанных диалогов.
- Предупреждения импорта лежат в `ImportResult.errors` с префиксом `warning:`. `POST /transcripts` возвращает их в дополнительном поле `warnings`.
- Повторный импорт обновляет запись и `audio_url`. Прошлые запуски хранят свой снимок.
- `latest_total`, `gross_error` у диалога и `gross_error` у запуска показывают текущее состояние после решений. Экспорт отдаёт только исходные значения.
- Экспорт берёт последний запуск каждого диалога. Диалоги без запуска идут со статусом `not_evaluated`. Необязательный параметр `checklist_id` сужает выборку до одного чек-листа.
- Запуск по чек-листу чужого канала не блокируется, но получает причину проверки `channel_not_in_checklist`.
- В `evaluate` снимок передаётся без `audio_url`.
