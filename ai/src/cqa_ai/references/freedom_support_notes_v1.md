- Где тариф: в веб-версии вкладка «Кабинет», название под ФИО. В отчёте брокера первая страница, раздел «Информация о счёте».
- Реквизиты: «Меню → Пополнить → Перевод по реквизитам», выбрать валюту, скачать и передать в банк.
- Комиссия банка: без условий банка размер назвать нельзя.
- Изменение данных: «Меню → Поручения → Персональные данные → Изменение сведений».
- Вывод после изменения данных: подать заново после исполнения поручения и обновления данных, вторую заявку раньше не подавать.
- Отчёт брокера: «Меню → Отчёты и документы → Отчёт брокера», выбрать период, скачать.
- Вход: Freedom Finance Global это информационный сайт без входа. Веб-кабинет: tradernet.global или приложение Freedom Broker.
- Логин занят: логин остаётся в системе после закрытия счёта, нужен другой.
- Поиск бумаги: «Котировки», поиск по названию или тикеру, сверить карточку бумаги.
- Маржа: «Настройки приказа», снять «Использовать маржу» до отправки. Относится только к текущему приказу.
- D-счёт: для сбережений, торговый счёт для операций. Средства D-счёта напрямую для покупки не используются.
- Форма 1042-S предоставляется на английском.
- Отчётность холдинга: сайт Freedom Holding Corp., Investors, затем Financial Information.
- Nasdaq и NYSE это разные биржи.
- Поддержка помогает технически и не даёт инвестиционных рекомендаций. Советы даёт персональный менеджер.
- Отдельные бумаги покупаются только через трейдеров или внебиржевую сделку, хотя стакан отображается.
