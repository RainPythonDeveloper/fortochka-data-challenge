# ai

Оценка диалогов моделью: контракты, расчёт баллов, рубрика, промпт, проверка ответа и замеры точности. Пакет `cqa_ai`.

```bash
cd ai
uv sync
uv run pytest
```

## Модель

Оценку выполняет `google/gemma-4-31b-it` через бесплатный API NVIDIA. Ключ создаётся на [build.nvidia.com](https://build.nvidia.com/settings/api-keys).

| Переменная | Значение |
|---|---|
| `NVIDIA_API_KEY` | Ключ `nvapi-...` |
| `LLM_PROVIDER` | `nvidia` |
| `LLM_MODEL` | `google/gemma-4-31b-it` |
| `LLM_FALLBACK_MODEL` | Запасная модель, например `mistralai/mistral-large-4-1t-a52b` |
| `CQA_LLM_TIMEOUT_S` | Предел ожидания ответа, по умолчанию 120 секунд |
| `CQA_ALLOW_VOICE_TO_CLOUD` | `1` разрешает отправку звонков в модель |

Бесплатный API записывает запросы и просит не отправлять персональные данные. В реальных звонках они есть, поэтому по умолчанию звонки в модель не уходят и получают статус `failed` с понятной причиной.

## Как устроена оценка

1. `annotate.py` находит в служебных событиях удержание, разрывы записи, завершение и подтверждение личности.
2. `rubric.py` и `prompt.py` собирают запрос только из данных чек-листа. Заметки команды действуют, пока смысл критерия не менялся.
3. `providers/nvidia_provider.py` отправляет запрос и по очереди пробует режимы строгого JSON.
4. `validator.py` проверяет ответ: критерии, допустимые значения, существование реплик, точность цитат.
5. `pipeline.py` ограничивает повторы, делает одну починку контракта и одно переключение на запасную модель.
6. `scoring.py` считает баллы. Модель их не считает.

Сбой остаётся статусом `failed` и не превращается в ноль.

## Замер точности

```bash
set -a; source ../.env; set +a
uv run python -m cqa_ai.evaluation run --data ../data/raw/dev.json --split tune --limit 3
uv run python -m cqa_ai.evaluation report --run data/runs/tune-google_gemma-4-31b-it
```

Части `tune`, `compare` и `holdout` заданы в `src/cqa_ai/evaluation/manifest.json`, семейства сценариев не разрываются. По умолчанию оцениваются только чаты, повторный запуск пропускает готовые диалоги и бережёт квоту. После трёх сбоев подряд прогон останавливается. Результаты лежат в `data/`, эта папка вне Git.

`labels/reference_v1.json` содержит черновую разметку 28 чатов из части `tune`. Это не эталон организаторов и не проверено людьми. Разметка используется только для замеров и никогда в оценке.
